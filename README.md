# Masquerade · 易容术

一个 Paper 服务器的万圣节活动插件：**潜行右键方块或生物取样，喝下得到的「易容术」，三分钟内变成那块方块，或那只生物。**

你可以变成点亮的熔炉、信标、门、床，也可以变成僵尸、苦力怕、山羊、监守者；变成生物后还能用它的视角和它的招牌动作去整蛊别人。

---

## 1. 环境要求

| 项 | 要求 |
|---|---|
| 服务端 | Paper 26.2（API 26.2） |
| Java | Java 25 |
| 前置插件 | **MCZJUItemCreator 1.1.0**（必须安装，否则本插件不会启用） |
| 客户端 | 原版客户端即可，不需要资源包或模组 |

> 本插件只支持 Paper 26.2；其他版本没有做兼容。

---

## 2. 安装

1. 先把 **MCZJUItemCreator 1.1.0** 放进 `plugins/`。
2. 把 `Masquerade-1.0.0.jar` 放进 `plugins/`。
3. **完整重启服务器**（`/reload` 不够）。
4. 首次启动会生成：
   - `plugins/Masquerade/config.yml`
   - `plugins/Masquerade/items/morphpotion.yml`
5. 给管理员权限节点 `masquerade.admin`（默认 OP 拥有）。

看到启动日志里的「Masquerade 已启用」和「易容药水模板已就绪」就表示安装成功。

---

## 3. 三分钟上手

如果你只是想先玩一遍：

```text
/masq item morphpotion 16
```

1. 主手拿着「易容药水」。
2. **潜行 + 右键一个方块**，得到「易容术」。
3. 喝下「易容术」。
4. 你会变成那个方块，持续三分钟。
5. 想提前退出：**蹲下 + 右键**，或者输入 `/masq end`。

如果服主已经给你发了「易容药水」，直接从第 2 步开始即可。

---

## 4. 取样：把东西变成易容术

### 4.1 操作

| 步骤 | 要求 |
|---|---|
| 主手 | 必须拿着「易容药水」 |
| 动作 | **潜行（Shift）+ 右键** |
| 目标 | 一个方块，或一个生物 |
| 消耗 | 每次消耗 **1 瓶**易容药水 |
| 冷却 | 每次取样后 **1 秒**冷却 |

成功后聊天栏会提示「已取样：<名称>」，物品栏里会出现对应的「易容术」。

### 4.2 可以取样什么

- **方块**：除空气外都可以。点亮的熔炉、点亮的铜灯、楼梯朝向、门的上半/下半、含水方块都会保留精确状态。
- **生物**：大多数可生成的生物，包括动物、村民、幼体、史莱姆、岩浆怪；凋灵和末影龙已排除。
- 空手、副手拿药水、没有潜行、拿普通药水，都不会取样。
- 如果背包满了，产物会掉在脚下，不会凭空消失。

### 4.3 原料药水不能直接喝

「易容药水」是原料，直接喝会被拦下并提示你先去取样。取到「易容术」之后，喝的是「易容术」，不是原料。

---

## 5. 方块易容

喝下「易容术（方块）」后，你会：

- 变成该方块的样子，方块会跟着你移动和转身；
- 尺寸缩小到 **50%**；
- 获得 **3 分钟隐身**；
- 持续 **3 分钟**，或被提前结束。

### 5.1 两格方块

门、床、高花这类占两格的方块会显示**完整两格**：

- 门：下半 + 上半；
- 床：脚 + 头（会跟着你转身）；
- 高花：下半 + 上半。

不会只剩一半。

### 5.2 蹲下自动对齐

方块形态下，**只按一下蹲**：

- 自动传送到你所在方块的 **x/z 中心**；
- 朝向自动矫正到 **90° 的倍数**（0 / 90 / 180 / 270）；
- 脚底高度不变，不会把你塞进方块里。

这个功能适合在活动场地里把方块摆正。骑马或坐船时不会强制传送。

### 5.3 退出

- **蹲下 + 右键**（方块、空气、实体都可以）；
- 或 `/masq end`；
- 或等 3 分钟自动结束；
- 死亡、喝牛奶（隐身被移除）也会结束。

---

## 6. 生物易容

喝下「易容术（生物）」后，你会附身到那只生物身上，持续 **3 分钟**。

### 6.1 操控

| 按键 | 作用 |
|---|---|
| W / S | 前进 / 后退 |
| A / D | 左右转向 |
| 空格 | 跳跃 / 上升 |
| 下蹲 | 下降；狐狸蹲伏、狼/猫坐下等姿态 |
| Ctrl | 疾跑（部分生物更快） |
| 左键 | 该生物的特色动作 |
| 右键 | 该生物的叫声或特色动作 |

> 生物附身时没有鼠标俯仰视角，左右键的瞄准是**水平方向**。这是原版客户端的限制。

### 6.2 部分生物的特色动作

| 生物 | 左键 / 右键效果 |
|---|---|
| 鸡 | 左键下蛋 |
| 狐狸 | 左键睡觉 / 醒来 |
| 河豚 | 左键膨胀 / 收缩 |
| 海豚 | 左键给附近玩家海豚的恩惠 |
| 马 / 驴 / 骡 | 左键仰身嘶鸣 |
| 骆驼 | 左键趴下 / 起身 |
| 熊猫 | 左键打滚 |
| 山羊 | 左键冲撞前方目标 |
| 唤魔者 | 左键召唤十字尖牙 |
| 女巫 | 左键喝一瓶剧毒药水 |
| 骷髅 及其变种 | 左键拉弓 |
| 末影人 | 左键进行一次传送 |
| 羊驼 | 左键吐一口痰 |
| 嗅探兽 | 左键开始挖掘远古植物 |
| 雪傀儡 | 左键丢一个雪球 |
| 旋风人 | 左键发射风弹 |
| 监守者 | 右键发射音波 |
| 鱿鱼 / 发光鱿鱼 | 左键喷墨 |
| 鹦鹉 | 左键坐下 / 起身 |

其他生物使用默认行为：有近战能力的生物左键播放攻击动作并击退目标，右键播放环境音。

### 6.3 伤害说明

这个插件以整蛊为主：

- 绝大多数自定义动作**不造成伤害**；
- 但山羊冲撞、唤魔者尖牙、羊驼口水、监守者音波等**原版技能**会保留它们原本的伤害或击退；
- 苦力怕只膨胀、不爆炸，任何生物都不会破坏方块；
- 附身期间你的本体仍然可能被其他玩家或环境伤害打到。

### 6.4 退出

- **蹲下 + 右键**；
- 或 `/masq end`；
- 或等 3 分钟；
- 死亡、切世界、退出游戏会结束附身。

---

## 7. 退出方式总表

| 方式 | 方块形态 | 生物形态 |
|---|---|---|
| 蹲下 + 右键 | 可以 | 可以 |
| `/masq end` | 可以 | 可以 |
| 3 分钟到点 | 可以 | 可以 |
| 死亡 | 可以 | 可以 |
| 切世界 | 方块会继续跟随 | 会结束附身 |
| 喝牛奶 | 隐身被移除，会结束 | 不适用 |

> 生物形态下，单纯按蹲是下降/姿态，单纯右键是叫声；**按住蹲再右键**才是退出。

## 8. 指令与权限

| 指令 | 说明 | 权限 |
|---|---|---|
| `/masq item <方块\|生物> [数量]` | 获得指定方块或生物的「易容术」 | `masquerade.admin` |
| `/masq item morphpotion [数量]` | 获得「易容药水」 | `masquerade.admin` |
| `/masq clear [选择器]` | 清除玩家的方块 + 生物易容；留空为 `@s`；不接受 `@e` | `masquerade.admin` |
| `/masq end` | 结束自己的易容 | `masquerade.use`（默认所有玩家可用） |

补充：

- `/masq item furnace[lit=true]` 可以指定方块状态；不写状态则使用默认状态。
- 数量上限默认 2304；放不下的部分掉在脚下。
- `/masq clear @a` 会清除所有在线玩家的易容；`/masq clear` 只清自己。
- `masquerade.admin` 默认 OP；`masquerade.use` 默认所有玩家。

## 9. 物品与提示

### 9.1 易容术

- 名称紫色，不可堆叠；
- 使用冷却 1 秒；
- tooltip 显示「隐身」，对应 3 分钟隐身；
- lore 会显示你要变成的方块/生物名称；
- 喝下后由插件接管变身效果。

### 9.2 易容药水

- 可堆叠 64；
- 是取样工具，**不能直接喝**；
- tooltip 同样显示「隐身」，表示它是隐身药水的原料；
- 液体颜色默认 `#99BB88`。

### 9.3 图标

- 有物品形态的方块会显示对应图标；
- 没有物品形态的方块（水、耕地、活塞头等）会显示为带颜色的易容药水；
- 点亮的熔炉/铜灯在背包里只能显示未点亮图标，但变身之后身上是准确状态。

## 10. 配置

配置文件都在 `plugins/Masquerade/`：

- `config.yml`：时长、尺寸、显示、提示文本、物品名称/lore。
- `items/morphpotion.yml`：易容药水的 ItemCreator 定义。

**改完配置需要完整重启服务器。**

### 10.1 常用配置

```yaml
effect:
  duration-seconds: 180      # 变身持续秒数
  scale: 0.5                 # 方块形态缩小比例
  invisibility: true         # 是否隐身
  snap-on-sneak: true        # 方块形态按蹲自动对齐

display:
  scale: 1.0                 # 方块展示大小
  hide-from-self: false      # 自己是否看不见自己身上的方块
  view-range: 1.0

items:
  masquerade:
    name: "<light_purple>易容术</light_purple>"
    mob-name: "<light_purple>易容术</light_purple>"
    lore:
      - "<gray>饮用后，你将变为 %s </gray>"
      - "<gray>按 <gold>下蹲 + 右键</gold> 退出易容</gray>"
      - "<dark_gray>药效持续三分钟</dark_gray>"
```

### 10.2 文本占位符

- 物品名称/lore 使用 MiniMessage，例如 `<light_purple>易容术</light_purple>`；
- 物品 lore 里的 `%s` 会替换成客户端翻译的方块名/生物名；
- `messages` 里的提示是纯文本，支持 `%s` / `%d`；
- 所有玩家可见文本都在 `config.yml` 的 `messages` 段，可以自行改成服务器风格。

### 10.3 其他可调项

| 键 | 作用 |
|---|---|
| `items.morphpotion.color` | 药水液体颜色 |
| `items.morphpotion.show-invisibility-effect` | 药水 tooltip 是否显示「隐身」 |
| `items.morphpotion.sample-cooldown-seconds` | 取样冷却秒数 |
| `items.masquerade.cooldown-seconds` | 易容术使用冷却秒数 |
| `items.block-blacklist` | 禁止取样的方块列表 |
| `items.invisible-icon-blocks` | 图标不可见、改用易容药水外观的方块 |
| `commands.item-count-max` | `/masq item` 数量上限 |
| `debug` | 排障日志开关 |

## 11. 从源码构建

需要 JDK 25 和 Maven：

```bash
mvn -B clean package
```

产物：

```text
target/Masquerade-1.0.0.jar
```

`paper-api` 和 `MCZJUItemCreator` 都是 `provided`，不会打进 jar；服务器上仍然需要安装 MCZJUItemCreator。

## 12. 常见问题

**Q：喝「易容药水」没反应？**  
A：它是原料，不能直接喝。请潜行 + 右键方块/生物取样，得到「易容术」后再喝。

**Q：`/masq` 提示没有权限？**  
A：`/masq item` 和 `/masq clear` 需要 `masquerade.admin`（默认 OP）；`/masq end` 需要 `masquerade.use`（默认所有玩家）。

**Q：改了配置没生效？**  
A：配置只在启动时读取，必须完整重启服务器，`/reload` 不够。

**Q：方块图标是空白的？**  
A：部分方块没有物品形态，或者图标本身不可见。插件会把它显示为带颜色的易容药水外观。

**Q：门/床为什么只剩一半？**  
A：请确认服务器加载的是最新版插件，并完整重启。当前版本会把门、床、高花显示成完整两格。

**Q：生物附身时鼠标不能上下看？**  
A：原版客户端在相机附身状态下不发送俯仰输入，左右键只能水平瞄准；这是客户端限制。

**Q：服务器重启后还保留易容吗？**  
A：方块形态在 3 分钟内重新登录会按剩余时间续上；生物形态退出游戏即结束，重新登录不会继续附身。

**Q：生物附身提前退出后还隐身？**  
A：当前版本会在退出时收回药水隐身；如果仍然出现，请把服务端日志和复现步骤发给服主。
